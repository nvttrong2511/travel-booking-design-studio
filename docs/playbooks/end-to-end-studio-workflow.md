# End-to-End Studio Workflow

## Phase 1 — Frame
Capture the user, journey stage, decision, business outcome, platform, data, constraints, emotional target, and trust risks.

## Phase 2 — Diverge
Use `/create-concept`. Produce at least three concepts with different structures, interactions, and visual languages.

## Phase 3 — Critique
Use `/challenge-design`. Remove clone-like, decorative, confusing, or technically fragile ideas.

## Phase 4 — Select
Choose a direction using originality, usefulness, emotional fit, trust, accessibility, and feasibility. Record the rejected options and why.

## Phase 5 — Systemize
Use `/generate-design-language`. Define tokens, composition rules, component grammar, motion, imagery, and responsive transformations.

## Phase 6 — Map
Document the journey, page beats, decision points, states, data variability, and signature moments.

## Phase 7 — Implement
Use `/implement-concept`. Build the smallest complete slice while preserving the concept thesis.

## Phase 8 — Review
Use `/design-review`. Revise until the quality gates pass.

## Phase 9 — Document
Store the selected concept, design language, component rules, decisions, validation, and remaining risks close to the implementation.
