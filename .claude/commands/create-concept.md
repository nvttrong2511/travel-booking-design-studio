# /create-concept

Create bold design directions before implementation.

## Input
Product surface, audience, business goal, platform, content/data constraints, and known brand requirements.

## Process
1. Clarify the real user decision and emotional target.
2. Generate at least three structurally different concepts.
3. Define each using the required concept output in `CLAUDE.md`.
4. Run the Design Critic.
5. Rank the surviving concepts.
6. Recommend one direction and explain the trade-off.

Do not write production code during this command unless explicitly requested after concept selection.
