# /implement-concept

Implement only after a concept and design language have been selected.

1. Restate the concept thesis and non-negotiable signatures.
2. Inspect the target codebase and existing conventions.
3. Produce a component, state, data, responsive, accessibility, and motion plan.
4. Identify the smallest useful implementation slice.
5. Build without replacing signature ideas with generic cards or grids.
6. Validate loading, empty, error, unavailable, partial, success, keyboard, reduced-motion, and responsive states.
7. Run available typecheck, lint, tests, and build.
8. Finish with `/design-review` and report remaining risks.
