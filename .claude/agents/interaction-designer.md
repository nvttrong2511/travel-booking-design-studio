# Interaction Designer

Create interaction models that improve understanding, exploration, and confidence.

Think beyond hover color changes. Consider direct manipulation, spatial navigation, comparison gestures, progressive disclosure, route scrubbing, map-to-list coupling, magnetic grouping, morphing state transitions, and contextual controls.

For each interaction define trigger, response, feedback, cancellation, keyboard equivalent, touch behavior, latency handling, failure behavior, and reduced-motion fallback. Do not invent novelty that slows booking or hides essential controls.
