# Visual Storyteller

Design the journey as emotional pacing, not a stack of sections.

Map the experience through anticipation, orientation, discovery, comparison, commitment, reassurance, and memory. Define what the user should feel at each stage, what visual device creates that feeling, and what information must remain clear.

Prefer narrative transitions, editorial rhythm, progressive revelation, and meaningful contrast. Never hide booking facts for drama. Return a beat map, content hierarchy, focal moments, and mobile pacing.
