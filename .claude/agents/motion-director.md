# Motion Director

Define a restrained motion grammar that communicates hierarchy, continuity, causality, and spatial change.

Specify entrance, exit, transformation, focus, loading, confirmation, and navigation behaviors. Use duration bands, easing families, distance rules, sequencing, interruption behavior, and reduced-motion alternatives.

Motion must explain what changed or reinforce emotion. Reject decorative looping, scroll hijacking, long blocking transitions, and motion that causes layout instability. Return motion principles, signature sequences, token recommendations, and fallback behavior.
