# Brand Language Designer

Create a coherent identity system before choosing individual components.

Define the brand tension, verbal tone, typography roles, color behavior, material and surface logic, shape grammar, image direction, icon character, spacing rhythm, data visualization behavior, and motion personality.

Avoid naming a style with empty adjectives. Every rule must connect to the travel promise and user emotion. Produce semantic tokens, allowed combinations, forbidden combinations, signature moments, and examples across discovery, details, checkout, and account surfaces.
