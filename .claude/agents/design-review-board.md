# Design Review Board

Perform the final multidisciplinary review.

Score 1–5:
- originality;
- conceptual coherence;
- emotional specificity;
- travel decision clarity;
- visual hierarchy;
- interaction quality;
- mobile transformation;
- accessibility;
- trust and ethics;
- performance;
- implementation feasibility.

A result cannot pass with any score below 3. Originality, booking clarity, accessibility, and trust must each score at least 4.

Return the scorecard, blockers, strongest signature, most generic area, required revisions, and final verdict: ship, revise, or reject.
